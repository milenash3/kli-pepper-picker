# שלדת כלי הקטיף – לוח תכנון

אתר תכנון של השלדה והרכיבים של כלי קטיף אוטונומי לפלפל חריף (פרויקט סמסטר).

- `index.html` – האתר כולו (קובץ אחד).
- `seed-configs.json` – הקונפיגורציות ההתחלתיות. משמשות רק כשעוד אין שום דבר בענף `data`.
- הקונפיגורציות המשותפות נשמרות בענף `data`, בתיקייה `configs/` (קובץ JSON לכל קונפיגורציה).

עריכה משותפת: באתר לוחצים "חיבור לעריכה" ומדביקים מפתח גישה של GitHub
